## ✨ Core Features

*   **Mobile-First Responsive Layout:** Designed using CSS Flexbox and CSS Grid to ensure it looks perfect on mobile phones, tablets, and desktops.
*   **Dark / Light Theme Toggle:** Implemented using CSS Variables and JavaScript. The user's preference is saved in `localStorage` so it persists on page reload.
*   **Smooth Scrolling Navigation:** CSS `scroll-behavior: smooth` allows users to glide seamlessly between sections.
*   **Dynamic Skills Carousel:** An infinite, right-to-left animated marquee displaying my tech stack (inspired by modern UI trends). It pauses on hover for better accessibility.
*   **Interactive Project Modals:** Instead of leaving the page, clicking "View Details" on a project opens a JavaScript-powered modal popup to display more information.
*   **Mobile Hamburger Menu:** A fully functional, animated hamburger menu for smaller screens.

## 🛠️ Technical Stack

*   **HTML5:** Semantic structure (Header, Main, Section, Article, Footer) for better accessibility and SEO.
*   **CSS3:** Custom properties (Variables) for theming, Flexbox, CSS Grid, Keyframe animations, and Media Queries.
*   **JavaScript (ES6+):** DOM manipulation, Event Listeners, and LocalStorage for theme persistence.
*   **Deployment:** Hosted live via [Vercel / Netlify / GitHub Pages].
